# 飛行物理模型

實作：`wasm/physics-engine/src/{math,atmosphere,aircraft,flight}.rs`。全部使用 SI 單位與弧度。

## 座標系

- **世界**：+X 東、+Y 上、−Z 北（右手系）。
- **機體**：+X 機頭、+Y 機頂、+Z 右翼（右手系）。
- 四元數 `q` 把機體向量轉到世界。機體角速度 ω 在機體座標：ωx 滾轉（+ = 右翼下）、ωy 偏航（繞 +Y，**+ = 向左**，所以向右偏航為負）、ωz 俯仰（+ = 抬頭）。
- 控制輸入：`pitch +1` = 拉桿（抬頭）、`roll +1` = 右滾、`yaw +1` = 右舵、`throttle` 0..1。

## 大氣（ISA）

對流層 `T = 288.15 − 0.0065 h`、`p = 101325 (T/288.15)^5.255876`；11 km 以上等溫 216.65 K。`ρ = p/(R T)`，`R = 287.053`。高度夾在 −500…30000 m。

## 動力學

```
v_b   = q⁻¹ v_world          α = atan2(−v_b.y, v_b.x)      β = asin(v_b.z / |v|)
q̄     = ½ ρ V²              M = V / a
L     = q̄ S CL(α)  · (ẑ × v̂)/|…|        D = q̄ S CD · (−v̂)       Y = −q̄ S CYβ β · ẑ
T     = throttle · Tmax · (ρ/ρ0)^0.8    （機頭方向）
```

- `CL(α)`：`|α| ≤ α_stall` 線性（`CL0 + CLα α`），超過後在 0.12 rad 內以 smoothstep 混合到 `1.1 sin 2α`（類平板曲線），所以失速是平滑下降而非斷崖。
- `CD = CD0 + k CL² + blend · 2.0 sin²α + 1.5 · clamp(M − 0.85, 0, 0.5)²`（最後一項為粗略的穿音速阻力上升）。
- 力矩（`p̂ = ωx b/2V` 等，V 下限 30 m/s）：
  - 滾轉 `Mx = q̄ S b (Clp p̂ + Clδa·roll − Clβ β)`
  - 偏航 `My = q̄ S b (−Cnβ β − Cnδr·yaw + Cnr r̂)`
  - 俯仰 `Mz = q̄ S c (Cm0 + Cmα sin α + Cmq q̂ + Cmδe·pitch)`
- 轉動：`I ω̇ = M − ω × Iω`（對角慣量）。姿態：`q̇ = ½ q ⊗ (0, ω)`，每子步正規化。
- 積分：RK4（位置、速度、姿態、角速度）；30 Hz 外層步長拆成 4 個 1/120 s 子步。舵面與引擎為一階落後，每子步以精確指數更新；燃油每子步扣除。結果對相同輸入逐位元可重現（有測試）。
- 質量 `m = m_empty + fuel`；慣量乘以 `m / m_gross`。轉動方程含慣量積 Ixy（x 機頭、y 機頂的對稱面）：`[Ixx −Ixy; −Ixy Iyy][ω̇x; ω̇y] = M − ω×Iω`。
- 馬赫相依：`CLα(M) = CLα · f(M)`，`f` 為 Prandtl-Glauert（M ≤ 0.8）→ 平滑過渡 → `1.1/√(M²−1)`（M ≥ 1.2）；波阻 `CDw` 在 M 0.85–1.1 以 smoothstep 升至 `cd_wave`，之後 `∝ M^-0.6`；M 0.85–1.3 `Cmα × (1 + 0.7s)`，M 0.9–1.5 升降舵效 × `(1 − 0.35s)`。
- 推力：`power`（油門經 τ 1.1 s / 0.7 s 落後）→ 乾推力 `Tmil · (0.05 + 0.95 power/0.85) · (ρ/ρ0)^0.8 · (1 + 0.4M…)`；power > 0.88 起混入後燃器推力（到 120 kN）。燃油流量 = 乾推力 × 2.3e-5 + 後燃器增量 × 5.6e-5 kg/(N·s)。
- 交叉耦合：反向偏航 `Cnδa`、方向舵滾轉 `Clδr`、偏航率滾轉 `Clr`。
- 飛控保護：拉桿指令乘以 `clamp((9 − nz_pred)/1.5)` 與 `clamp((0.95 α_stall − α_pred)/0.06)` 的較小者（推桿對稱，限 −3 g）；`nz_pred = nz + 0.2 ωz V/g`、`α_pred = α + 0.3 ωz`。
- 風 / 紊流：`Sim.wind` + 以正弦和構成的確定性紊流（強度隨高度指數衰減），預設關閉。
- 碰撞：地面平面 `y = 0` 與靜態建築（軸對齊方塊，底在 `y = 0`）。機身用 `AircraftParams::hull` 的點集合近似（機體座標），每個子步檢查每個點從上一子步到這一子步的線段：對地面看 `y ≤ hull_radius`，對建築用「線段 vs 向外膨脹 `hull_radius` 的方塊」的 slab 測試（不會穿牆）。取最早的接觸時間比例 `t`，把機體停在該位置，速度與角速度歸零，記錄原因（1 地面 / 2 建築）與墜毀時刻。細節見 `collision.rs`。
- 撞擊預測：沿目前速度向量直線外推 8 秒（每 0.25 s 一段），對地面與建築（額外 4 m 餘裕）求最早相交時間，寫入快照欄位 25（99 = 無）。
- 警告（`warnings.rs`）：位元遮罩，位元序即優先序（0 最高）。`PULL UP` 另外模擬逃脫軌跡：反應延遲 0.7 s + 改平時間（傾角 / 2 rad/s）後，以 `0.85 × g_avail` 朝世界向上拉起（質點、14 s、0.1 s 步長），若仍碰地面或建築才觸發；`g_avail = min(9, q S CLmax(M) / (m g))`。拉得起來時只顯示 `TERRAIN`。其餘條件：失速角、`0.85 α_stall`、q > 62 kPa 或 M > 2.0、過載超限 0.5 g、SINK RATE（高度 < 1000 m 且下降率 > max(15, 0.12 h) m/s）、坡度 > 69° 且高度 < 400 m、燃油 < 25 % / 10 % / 0。
- 數值出現 NaN/∞ 時自動重置。

## 假設與誤差來源

1. 係數量級參考公開的輕型戰鬥機資料，再為了好操作而手調；**不代表任何真實飛機**。
2. 氣動係數與馬赫、α 無表格相依（僅有失速混合與阻力上升的簡化項）。
3. 預設無風與紊流；無襟翼 / 減速板 / 起落架；馬赫與迎角相依僅為簡化解析式（無資料表）。
4. 以 Python 等價原型檢查過的行為（起始條件下）：放手飛行約 2.9° 迎角配平並出現緩慢長週期起伏；拉桿 0.5 s 後 ωz>0；右滾 0.5 s 後 ωx>0 且右翼低於地平線；右舵 0.5 s 後 ωy<0 且機頭偏東；持續全拉桿 5 s 後迎角達 26°、速度降到約 124 m/s（失速）。
