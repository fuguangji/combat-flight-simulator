↑ / ↓俯仰（↓ = 拉桿，機頭抬起）

            
← / →滾轉

            
A / D方向舵（左 / 右）

            
W / S油門增加 / 減少

            
B / RADAR開啟雷達面板；點選接觸點，再按「鎖定」。Tab 可循環切換目標。雷達範圍與靈敏度可在駕駛艙設定。

            
F / MISSILE先鎖定目標，再按 F 或駕駛艙 MISSILE。空對空／空對地裝備只能攻擊對應類別；命中會消耗彈藥並摧毀訓練目標。

            
G / CANNON按住 G 持續射擊；駕駛艙 CANNON 按鈕會射出短點放。機砲有 600 發彈藥，需將機首瞄準空中目標。

            
地形破壞以空對地裝備鎖定橘色地面站點並發射；命中會摧毀站點並留下持續可見的地面撞擊痕跡。訓練目標與命中判定皆為虛構遊戲機制。

            
STORE / 裝備發射目前配置的裝備；需先選取並鎖定相符的雷達接觸點。

            
AUTO / 自動駕駛切換巡航輔助。

            
滑鼠點擊飛行畫面鎖定滑鼠，移動滑鼠即可環顧；Esc 解除鎖定並暫停。滾輪縮放視角，C 或中鍵回正。只轉動視角，不改變飛機操控軸。

            
C / 滑鼠中鍵視角回正

            
Esc / P暫停

            
觸控左下四個方向鈕＝▲ 壓機頭 / ▼ 拉機頭 / ◀ ▶ 左右滾轉（按住越久動作越大）、右側滑桿＝油門（頂端＝後燃器）、拖曳畫面＝環顧（放開保持）、右上 ❚❚＝暫停

            
N（教學模式）略過目前步驟

            
R重新開始
